SCHOOLPILOT API Documentation

Complete reference with required fields for all API endpoints

Authentication

JWT Token-Based Authentication

All protected endpoints require a JWT token in the Authorization header:

Authorization: Bearer <access_token>

Accounts Module

Authentication & User Management
POST /api/accounts/register/

Register a new user account

Permissions: Public (no token required)
Required Fields:
  • REQUIRED first_name - User's first name (string)
  • REQUIRED last_name - User's last name (string)
  • REQUIRED email - User's email (email format)
  • REQUIRED username - Unique username (string)
  • REQUIRED password - Password (string, write-only)
POST /api/accounts/token/

Obtain JWT access and refresh tokens

Permissions: Public
Required Fields:
  • REQUIRED email - User's email (string)
  • REQUIRED password - User's password (string)
POST /api/accounts/token/refresh/

Refresh access token using refresh token

Permissions: Public
Required Fields:
  • REQUIRED refresh - Refresh token (string)
GET /api/accounts/users/

List all users

Requires Authentication
GET /api/accounts/users/<user_id>/

Get details for a single user

Requires Authentication
PATCH /api/accounts/users/<user_id>/update/

Update user fields

Requires Authentication
Editable Fields (send only fields to update):
  • first_name, last_name, email, username, role, school, is_active, is_staff
POST /api/accounts/users/change-password/

Change password for authenticated user

Requires Authentication
Required Fields:
  • REQUIRED old_password - Current password (string)
  • REQUIRED new_password - New password (string)
  • REQUIRED confirm_new_password - Confirm new password (must match new_password)

Schools Module

School Management
POST /api/schools/add/

Permissions: super_admin only
Required Fields:
  • REQUIRED name - School name (string)
  • REQUIRED logo - School logo URL (string)
  • REQUIRED address - School address (string)
  • REQUIRED phone - School phone (string)
  • REQUIRED email - School email (string)
  • REQUIRED registration_number - School registration number (string)
  • REQUIRED motto - School motto (string)
GET /api/schools/view/<school_id>/

View school details

Permissions: super_admin only
PATCH /api/schools/update/<school_id>/

Update school details

Permissions: super_admin only
Editable Fields (send only fields to update):
  • name, logo, address, phone, email, registration_number, motto
Read-only Fields:
  • is_active, created_at, updated_at

Sessions & Terms Module

Permissions: school_admin or super_admin only
Required Fields:

View all academic sessions for a school

Permissions: school_admin or super_admin only
PATCH /api/schools/session/update/<session_id>/

Update academic session details

Permissions: school_admin or super_admin only
Editable Fields (send only fields to update):
  • school, name, start_date, end_date, is_current
Read-only Fields:
  • created_at, updated_at

General Notes

  • Authentication: All endpoints except registration and token endpoints require a valid JWT token in the Authorization header.
  • Role-Based Access: Many endpoints are restricted to specific user roles (admin, teacher, student, school_admin, super_admin).
  • Required vs Optional: All required fields must be provided. Optional fields can be omitted.
  • Editable vs Read-only: Editable fields can be modified via PATCH/PUT. Read-only fields are auto-generated or system-managed.
  • Response Format: All endpoints return JSON responses with appropriate HTTP status codes.
  • Date Format: Use ISO 8601 format for dates (YYYY-MM-DD) and datetimes (YYYY-MM-DDTHH:mm:ssZ).

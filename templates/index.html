Welcome to SCHOOLPILOT API

This is the homepage for the SCHOOLPILOT API.

Use the sections below to explore the implemented API endpoints.

API Documentation

All API Endpoints

Base path: /api/accounts/

POST /api/accounts/register/
Register a new user. Fields: first_name, last_name, email, username, role, school, password1, password2
POST /api/accounts/token/
Obtain JWT tokens (access, refresh). Body: {"email","password"}
POST /api/accounts/token/refresh/
Refresh access token. Body: {"refresh"}
GET /api/accounts/users/
List users (requires Authentication).
GET /api/accounts/users/<user_id>/
Get details for a single user (requires Authentication).
PUT / PATCH /api/accounts/users/<user_id>/update/
Update user fields (requires Authentication).
POST /api/accounts/users/change-password/
Change password for authenticated user. Body: {old_password, new_password, confirm_new_password}.

Base path: /api/schools/

POST /api/schools/add/
Create a new school. Requires user role super_admin.
GET /api/schools/view/<school_id>/
View school details (super_admin only).
PUT / PATCH /api/schools/update/<school_id>/
Update school details (super_admin only).

Base path: /api/schools/

POST /api/schools/session/create/
Create academic session. School admin or super admin only.
GET /api/schools/session/view/<school_id>/
View all academic sessions for a school. School admin or super admin only.
PUT / PATCH /api/schools/session/update/<session_id>/
Update academic session. School admin or super admin only.
POST /api/schools/term/create/
Create term within a session. School admin or super admin only.
GET /api/schools/term/view/<school_id>/
View all terms for a school. School admin or super admin only.
PUT / PATCH /api/schools/term/update/<term_id>/
Update term details. School admin or super admin only.
GET /api/schools/term/current/<school_id>/
Get current active term for a school. Requires Authentication.

Base path: /api/students/

GET / POST /api/students/
List all students (GET) or create new student (POST). Requires Authentication.
GET / PATCH / DELETE /api/students/<student_id>/
Get, update, or delete a student. Requires Authentication.
POST /api/students/<student_id>/promote/
Promote student to next class. Admin only.
GET /api/students/<student_id>/profile/
Get student profile with guardian information. Requires Authentication.
POST /api/students/bulk-upload/
Bulk upload students from CSV file. Admin only.

Base path: /api/teachers/

GET / POST /api/teachers/
List all teachers (GET) or create new teacher (POST). Requires Authentication.
GET / PATCH /api/teachers/<teacher_id>/
Get or update teacher details. Requires Authentication.
POST /api/teachers/<teacher_id>/assign-subjects/
Assign subjects to a teacher. Admin only.
GET /api/teachers/<teacher_id>/classes/
Get classes assigned to a teacher. Requires Authentication.

Base path: /api/academics/

GET /api/academics/classes/
List all classes. Requires Authentication.
POST /api/academics/arms/
Create a new class arm/section. Admin only.
GET /api/academics/subjects/
List all subjects. Requires Authentication.
POST /api/academics/subjects/assign/
Assign subjects to a class. Admin only.

Base path: /api/attendance/

POST /api/attendance/mark/
Mark attendance for students. Teacher only.
PATCH /api/attendance/<attendance_id>/
Update attendance record. Teacher only.
GET /api/attendance/
View attendance records. Requires Authentication.
GET /api/attendance/summary/
Get attendance summary report. Admin only.

Base path: /api/results/

GET /api/results/assessments/
List all assessments. Requires Authentication.
POST /api/results/scores/
Enter scores for students. Teacher only.
PATCH /api/results/scores/<score_id>/
Update student score. Teacher only.
GET /api/results/class/
Get class results. Requires Authentication.
POST /api/results/approve/
Approve class results. Admin only.
GET /api/results/student/<student_id>/
Get student's results. Requires Authentication.

Base path: /api/fees/

POST /api/fees/categories/
Create fee category. Admin only.
POST /api/fees/structures/
Assign fees to classes. Admin only.
GET /api/fees/invoices/
List fee invoices. Admin only.
GET /api/fees/invoices/<invoice_id>/
Get invoice details. Admin only.
POST /api/fees/payments/
Record fee payment. Admin only.
GET /api/fees/payments/history/
Get payment history. Admin only.

Base path: /api/communications/

GET / POST /api/communications/announcements/
List announcements (GET) or create announcement (POST). Create requires admin.
GET /api/communications/notifications/
Get user notifications. Requires Authentication.
PATCH /api/communications/notifications/<notification_id>/read/
Mark notification as read. Requires Authentication.

Base path: /api/timetable/

POST /api/timetable/
Create timetable. Admin only.
GET /api/timetable/class/<class_id>/
Get class timetable. Requires Authentication.
GET /api/timetable/teacher/<teacher_id>/
Get teacher timetable. Teacher only.

Base path: /api/reports/

GET /api/reports/attendance/
Get attendance reports. Admin only.
GET /api/reports/fees/
Get fees reports. Admin only.
GET /api/reports/academics/
Get academics/results reports. Admin only.

Base path: /api/subscriptions/

GET /api/subscriptions/plans/
Get available subscription plans. Requires Authentication.
GET /api/subscriptions/current/
Get current school subscription. School admin only.
POST /api/subscriptions/upgrade/
Upgrade to a new subscription plan. School admin only.

Base path: /api/audit/

GET /api/audit/logs/
Get system audit logs. Super admin only.

Endpoints shown reflect the routes currently registered in sms_prj/urls.py and the respective app `urls.py` files.

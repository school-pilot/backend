Welcome to SCHOOLPILOT API

This is the homepage for the SCHOOLPILOT API.

Use the sections below to explore the implemented API endpoints.

API Documentation

All API Endpoints

Base path: /api/accounts/

POST /api/accounts/register/
Register a new user. Fields: first_name, last_name, email, username, role, school, password1, password2
POST /api/accounts/token/
Obtain JWT tokens (access, refresh). Body: {"email","password"}
POST /api/accounts/token/refresh/
Refresh access token. Body: {"refresh"}
GET /api/accounts/users/
List users (requires Authentication).
GET /api/accounts/users/<user_id>/
Get details for a single user (requires Authentication).
PUT / PATCH /api/accounts/users/<user_id>/update/
Update user fields (requires Authentication).
POST /api/accounts/users/change-password/
Change password for authenticated user. Body: {old_password, new_password, confirm_new_password}.

Base path: /api/schools/

POST /api/schools/add/
Create a new school. Requires user role super_admin.
GET /api/schools/view/<school_id>/
View school details (super_admin only).
PUT / PATCH /api/schools/update/<school_id>/
Update school details (super_admin only).

No API routes for students are currently included under the project root (/api/students/ is not registered in `sms_prj.urls`).

If you add `path('api/students/', include('students.urls'))` to `sms_prj/urls.py`, endpoints will appear here.

No API routes for attendance are currently included under the project root.

Add `path('api/attendance/', include('attendance.urls'))` to `sms_prj/urls.py` to expose these endpoints.

Other apps (results, fees, communications, etc.) will be listed here when their URLconfs are included in the project `sms_prj/urls.py`.

Endpoints shown reflect the routes currently registered in sms_prj/urls.py and the respective app `urls.py` files.
